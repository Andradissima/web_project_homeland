TripleTen Art Gallery

O TripleTen Art Gallery é uma página web responsiva desenvolvida como parte dos estudos em desenvolvimento front-end. O projeto apresenta uma galeria artística digital com foco em narrativa visual, tipografia e adaptação de layout para diferentes tamanhos de tela.

A proposta principal foi construir uma interface fiel ao design fornecido, garantindo boa experiência de navegação em desktop, tablet e dispositivos móveis, utilizando boas práticas de HTML semântico, metodologia BEM e CSS responsivo.

⸻

Funcionalidades

- Layout totalmente responsivo para diferentes resoluções:
  - Desktop (1280px)
  - Tablet (768px)
  - Mobile (320px)
- Estrutura HTML semântica para melhor acessibilidade e organização do código.
- Uso da metodologia BEM (Block, Element, Modifier) para nomeação de classes e escalabilidade do projeto.
- Tipografia externa personalizada utilizando @font-face.
- Imagens adaptativas com ajuste proporcional ao tamanho da tela.
- Organização modular de estilos em múltiplos arquivos CSS.
- Compatibilidade com navegadores modernos.

⸻

Tecnologias

- HTML5
- CSS3
- Normalize.css
- @font-face

Técnicas aplicadas

- Design Responsivo (Responsive Design)
- Media Queries
- Flexbox
- Unidades fluidas (%, vw, max-width)
- clamp() para ajustes adaptativos
- Organização de arquivos em arquitetura BEM Flat
- Boas práticas de semântica HTML
- Otimização visual para diferentes breakpoints
